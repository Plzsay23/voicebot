# DeepFilterNet 플러그인 설정 하는법

- 적용 장점
    
    LADSPA 플러그인은 쉽게 말해 **"오디오용 범용 부품"**이라고 이해하시면 됩니다. 질문하신 내용은 이 부품을 어디에 끼워 쓰느냐에 따른 차이입니다.
    결론부터 말씀드리면, LADSPA를 사용하는 것은 **OS 레벨에 가까운 오디오 엔진(시스템 전체 소리 처리)**에 직접 개입하겠다는 의도로 많이 사용됩니다.
    **1. LADSPA Plugin이란?**
    **LADSPA**(Linux Audio Developer's Simple Plugin API)는 리눅스 환경에서 오디오 필터나 효과(리버브, 노이즈 제거 등)를 만들기 위한 **표준 규격**입니다.
    • **부품과 소켓:** LADSPA는 '부품'이고, 이를 로드하는 프로그램(Audacity, EasyEffects, Pipewire 등)은 '소켓'입니다. 규격만 맞으면 어떤 프로그램에서도 이 노이즈 제거 기능을 불러와 쓸 수 있습니다.
    • **특징:** 그래픽 화면(GUI)이 없는 경우가 많고, 오로지 **실시간 소리 처리 연산**에만 집중하도록 매우 가볍게 설계되었습니다.
    **2. LADSPA 사용 vs Python 사용의 차이구분LADSPA 플러그인 방식Python 라이브러리 방식주 목적실시간(Live)** 소리 처리**연구/개발/배치(Batch)** 처리**사용 환경**OS 오디오 엔진 (Pipewire, JACK 등)Jupyter Notebook, 개발 스크립트**성능(속도)**매우 빠름 (C/Rust 등으로 컴파일됨)상대적으로 느림 (인터프리터 오버헤드)**사용 예시**"내 마이크 소리에서 실시간으로 노이즈 제거""녹음된 100개 파일에서 한꺼번에 노이즈 제거"**복잡도**설치 및 설정이 까다로울 수 있음코드 몇 줄로 간편하게 실행 가능
    **3. OS 단위에서 사용한다는 의미인가?**
    **네, 맞습니다.** 하지만 정확히는 "커널" 단위는 아니고, **"OS 오디오 서버(Middleware)"** 단위라고 표현하는 것이 정확합니다.
    1. **애플리케이션 단위 (Python):** 사용자가 파이썬 프로그램을 실행할 때만 동작합니다. 특정 오디오 파일을 불러와서 처리하고 저장하는 방식에 가깝습니다.
    2. **OS/오디오 서버 단위 (LADSPA):** 시스템의 오디오 경로(Pipeline) 중간에 이 플러그인을 끼워 넣습니다.
        ◦ 예를 들어, 리눅스의 **Pipewire**나 **EasyEffects**에 이 플러그인을 등록하면, 디스코드를 하든, 줌 회의를 하든, 게임을 하든 **OS로 들어오는 모든 마이크 소리**에서 자동으로 노이즈가 제거됩니다.
        ◦ 즉, 상위 애플리케이션(디스코드 등)은 소리가 어디서 처리되는지 모르지만, 이미 깨끗해진 소리를 OS로부터 전달받게 됩니다.
    **4. LADSPA 플러그인 방식의 장점**
    • **무한 확장성:** 한 번 설정해두면 마이크를 사용하는 모든 앱에서 DeepFilterNet의 성능을 누릴 수 있습니다.
    • **최소한의 지연(Latency):** 실시간 대화에 최적화되어 있어 목소리가 밀리는 현상이 거의 없습니다.
    • **자원 효율성:** 파이썬 환경을 로드할 필요가 없어 CPU와 메모리 점유율이 훨씬 낮습니다.
    **요약하자면**
    • **파이썬**은 "이 모델이 얼마나 잘 작동하나?" 테스트하거나 파일 처리를 할 때 좋고,
    • **LADSPA**는 "내 마이크 소리를 평상시에도 깨끗하게 만들고 싶다"는 실사용 목적으로 쓸 때 최적의 방법입니다.
    DeepFilterNet: A Low-Complexity Speech Enhancement Framework
    이 영상은 DeepFilterNet이 실제 소음을 얼마나 효과적으로 제거하는지 시연하는 데모를 담고 있어, LADSPA 플러그인을 통해 실시간으로 적용했을 때 얻을 수 있는 결과물을 미리 확인하기 좋습니다.

**다음 내용을 복사해서 붙여넣으세요:**

```
context.properties = {
    log.level = 2
}

context.spa-libs = {
    audio.convert.* = audioconvert/libspa-audioconvert
    support.*       = support/libspa-support
}

context.modules = [
    { name = libpipewire-module-rt
        args = {
            nice.level = -11
        }
        flags = [ ifexists nofail ]
    }
    { name = libpipewire-module-protocol-native }
    { name = libpipewire-module-client-node }
    { name = libpipewire-module-adapter }
    { name = libpipewire-module-link-factory }

    { name = libpipewire-module-filter-chain
        args = {
            node.description = "DeepFilter Noise Canceling Source"
            media.name = "DeepFilter Noise Canceling Source"
            filter.graph = {
                nodes = [
                    {
                        type = ladspa
                        name = deepfilter
                        plugin = /home/YOUR_USERNAME/.ladspa/libdeep_filter_ladspa-0.5.6-x86_64-unknown-linux-gnu.so
                        label = deep_filter_mono
                        control = {
                            "Attenuation Limit (dB)" = 80
                        }
                    }
                ]
            }
            audio.position = [ MONO ]
            capture.props = {
                node.name = "deepfilter_capture"
                node.passive = true
                audio.rate = 48000
                stream.dont-remix = true
                node.target = "YOUR_MICROPHONE_DEVICE_NAME"
            }
            playback.props = {
                node.name = "DeepFilterMic"
                media.class = "Audio/Source"
                audio.rate = 48000
            }
        }
    }
]

```

# 6단계: systemd 서비스 생성

부팅 시 자동으로 DeepFilter가 시작되도록 systemd 서비스 생성

```
# systemd 사용자 서비스 디렉토리 생성
mkdir -p ~/.config/systemd/user/

# 서비스 파일 생성
nano ~/.config/systemd/user/pipewire-filter-chain.service

```

**다음 내용을 복사해서 붙여넣으세요:**

```
[Unit]
Description=PipeWire Filter Chain for DeepFilter
After=pipewire.service pipewire-pulse.service wireplumber.service
Requires=pipewire.service

[Service]
Type=simple
ExecStart=/usr/bin/pipewire -c %h/.config/pipewire/filter-chain.conf
Restart=on-failure
RestartSec=3

[Install]
WantedBy=default.target

```

# 7단계: 서비스 활성화

모든 서비스를 올바른 순서로 시작

```
# systemd 데몬 리로드
systemctl --user daemon-reload

# pipewire-filter-chain 서비스 활성화 (부팅 시 자동 시작)
systemctl --user enable pipewire-filter-chain.service

# 모든 서비스를 올바른 순서로 재시작
systemctl --user restart pipewire.service
sleep 2
systemctl --user start wireplumber.service
sleep 2
systemctl --user restart pipewire-pulse.service
sleep 2
systemctl --user start pipewire-filter-chain.service

# 잠시 대기 (서비스 초기화 시간)
sleep 3

```
