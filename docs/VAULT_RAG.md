# 볼트 RAG — 옵시디언 리서치위키를 제리가 참고하게 하기

PC 의 옵시디언 볼트(`C:\ysj\ResearchWiki`)를 음성비서의 참고자료로 쓴다.
"제리, 웨이크워드 오검출 어떻게 고쳤지" 하면 그 노트를 찾아 읽고 답한다.

**볼트를 파이에 복제하지 않는다.** PC 가 켜져 있을 때만 검색 서버가 뜨고, 파이는
발화마다 거기에 물어본다. PC 가 꺼져 있으면 조용히 참고자료 없이 답한다 —
`REMOTE_LLM_URL`([PC_LLM.md](PC_LLM.md))과 정확히 같은 정책이다. 볼트에는 개인
기록이 들어 있고 파이는 24시간 켜진 기기라, 그 둘을 붙이지 않으려고 이렇게 골랐다.

```
파이(항상 켜짐)                        PC(켤 때만)
  dialog_node ──질의──────────────▶ vault_server.py (:8081)  ← 볼트 읽기
              ◀──조각 3개(예산 내)──
              ──프롬프트───────────▶ llama.cpp server (:8080)
```

## 어떻게 검색하나

**문자 bigram BM25.** 임베딩 모델이 아니다. 이유가 셋 있다.

1. **질의가 STT 를 통과해서 온다.** "연합학습"이 "연합 학쓥"으로 들어와도
   bigram 3개 중 2개가 겹쳐서 살아난다(실측으로 확인).
2. **의존성이 없다.** 파이엔 이미 SenseVoice·silero·piper 가 onnxruntime 을
   물고 있어서 세션을 더 늘리고 싶지 않았다. 서버는 표준 라이브러리만 쓴다.
3. **병목이 검색이 아니다.** 아래 "컨텍스트 예산" 참고. 검색 품질을 올려도
   넣을 수 있는 양이 안 늘어난다.

형태소 분석기 없이 한국어가 되고, 178문서 2751조각에서 **1ms 안에** 끝난다.

`scripts/vault_aliases.json` 은 STT 가 흘려 듣는 고유명사를 되살린다
("브이엘에이" → `VLA` 를 검색어에 덧붙임). 치환이 아니라 **추가**라서 원문이
맞았을 때도 손해가 없다. 새 주제가 생기면 여기 한 줄 추가하면 되고, 서버를
재시작할 필요 없이 다음 재스캔에 반영된다.

## 컨텍스트 예산 — 이 기능의 진짜 비용

파이4 에서는 **프롬프트 토큰이 그대로 대기시간**이다(생성 2.2 tok/s). 그래서
붙일 수 있는 양에 상한을 두고, 그 상한을 **서버가** 지킨다(받아놓고 파이에서
자르면 마지막 조각만 통째로 날아간다).

| 변수 | 기본 | 언제 |
|---|---|---|
| `VAULT_MAX_CHARS_LOCAL` | 500 | 파이가 직접 생성할 때 |
| `VAULT_MAX_CHARS_REMOTE` | 1500 | PC 가 생성할 때(프롬프트 비용 없음) |

500자는 웹검색이 이미 쓰고 있는 봉투(3건×180자)와 같다. **이미 실사용으로
검증된 비용**이라 새로 늘어나는 지연이 없다는 뜻이다.

한도가 하나 더 있다. 자료를 붙이면 EXAONE 이 "요약해 드리겠습니다" 모드로
들어가 번호 목록을 뱉는다. 프롬프트로 "두 문장 안에"를 못 박아도 지키다 만다
(실측). 프롬프트는 최선노력이고 한도는 보장이므로 토큰으로 막는다 —
`MAX_TOKENS_CONTEXT`(120) / `REMOTE_MAX_TOKENS_CONTEXT`(200).

## 언제 볼트를 뒤지나

두 단계다. **트리거**가 "찾아볼까"를 정하고, **점수**가 실제로 붙일지 정한다.

- 트리거(`VAULT_TRIGGERS`): "논문 / 노트 / 기록 / 찾아 / 왜 / 어땠…". 넉넉하다.
  좁게 잡았더니 "TTS 를 왜 바꿨는지 기록 찾아줘"가 안 걸려서, 답이 볼트에
  그대로 있는데 LLM 이 "내부 데이터베이스에서 확인 가능합니다"라고 지어냈다.
  헛검색이 지어내는 것보다 낫다.
- 점수(`VAULT_MIN_SCORE`, 기본 13): BM25 는 term 이 하나만 겹쳐도 뭔가를
  돌려주므로 문턱이 없으면 "피자 시켜줘"에 논문이 딸려간다.

**2026-07-28 실측**(178문서, 질문 15개): 관련 있는 질문의 1위 점수 15.4~66.8,
무관한 질문("피자 시켜줘", "지금 몇 시야", "노래 불러줘") 3.9~10.7. 겹치지 않아
13 을 그 사이에 뒀다. **볼트가 커지면 다시 재야 한다.**

## 띄우기

`chat` 이 LLM 서버와 함께 알아서 띄운다(둘 다 "PC 켜져 있을 때만"이 전제라
생명주기를 맞췄다). 볼트 서버가 안 떠도 LLM 은 정상 동작한다.

따로 다루려면:

```bash
bash scripts/vault_search.sh
```

| 명령 | 하는 일 |
|---|---|
| `bash scripts/vault_search.sh` | 확인/기동 |
| `... --stop` | 종료 |
| `... --log` | 로그 |
| `... --test "질문"` | 검색만 해보기(점수와 함께 출력) |

venv 가 필요 없다(의존성 없음). `PC_LLM_NO_VAULT=1 chat` 으로 `chat` 의
자동 기동만 끌 수 있다.

첫 인덱싱은 178문서 기준 **약 6초**, 그 뒤로는 `.vault_index.pkl` 캐시에서
1초 안에 뜬다. 볼트가 바뀌면 백그라운드 스레드가 5분 안에 따라잡는다.

## 파이에서 PC 로 닿게 하기

[PC_LLM.md](PC_LLM.md) 의 mirrored 네트워킹이 이미 돼 있으면 **포트만 하나 더
열면 된다.** 관리자 PowerShell:

```powershell
New-NetFirewallRule -DisplayName "voicebot Vault 8081" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8081 -Profile Private
```

파이 `~/voicebot/.env`:

```
VAULT_SEARCH_URL=http://192.168.0.41:8081
```

`/v1` 같은 접미사가 없다. LLM 주소와 헷갈리기 쉽다.

확인:

```bash
curl -s http://192.168.0.41:8081/health
```

`{"ok": true, "docs": 178, ...}` 가 나오면 끝이다. dialog_node 는 기동할 때
한 번, 그다음은 발화마다(캐시 10초) 확인하고 없으면 조용히 넘어간다.
`[내 연구 노트 502자]` 같은 로그가 찍히면 붙은 것이다.

## 볼트에서 뺄 폴더

볼트에는 개인 기록도 있다. 음성비서에게 읽히고 싶지 않은 폴더는 WSL 쪽
환경변수로 뺀다(파이가 아니라 **서버**에서 거른다):

```bash
VAULT_EXCLUDE=06_Claude,05_Logs bash scripts/vault_search.sh
```

기본값은 아무것도 안 뺀다 — `06_Claude` 의 프로젝트 기억이 오히려 음성으로
묻기 좋은 내용("voicebot 어디까지 했지")이라 넣어뒀다. `.git`, `.obsidian`,
`99_Assets` 는 항상 제외된다.

## 알아둘 것

- **답의 정확도는 EXAONE 2.4B 의 한계를 그대로 받는다.** 조각 3개를 섞다가
  사실을 뒤집기도 한다 — 실제로 "DeepFilterNet 을 쓸 수 있게 되었다"고 답한 적이
  있는데, 노트에는 **못 써서 제거했다**고 적혀 있다. 검색은 맞았고 요약이 틀린
  것이라, 이건 모델을 키우지 않으면 안 없어진다. 볼트 RAG 의 답을 근거로
  중요한 판단을 하지 마라. 출처 파일을 직접 열어보는 게 맞다.
- **재인덱싱은 요청을 막지 않는다.** `scan_files()` 가 `/mnt/c`(9p)에서 4~5초
  걸려서, 처음엔 이걸 요청 처리 중에 돌리다가 파이의 1초 프로브가 그대로
  터졌다. 지금은 백그라운드 스레드가 돌고 인덱스를 통째로 갈아끼운다.
  (스트레스 테스트: 재스캔 10초 주기에서 요청 109회 최악 32ms, 실패 0)
- **WSL 이 오래 놀면 배포판이 내려가면서 서버도 같이 죽는다.** 그러면 파이 쪽엔
  "PC 가 꺼진 것"과 똑같이 보인다(조용히 RAG 없이 답함). `.wslconfig` 의
  `vmIdleTimeout` 을 늘리거나, 안 되면 `chat` 을 다시 치면 된다.
