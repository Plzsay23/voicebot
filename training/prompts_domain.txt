# 도메인 문장 뱅크 — 손으로 쓴 것. build_prompts.py 가 읽는다.
#
# 여기 있는 문장은 공개 코퍼스에서 절대 안 나오는 것들이다:
# 웨이크워드 "제리", 실제로 쓸 명령어, 그리고 '제리'와 헷갈리는 유사음.
# 공개 코퍼스는 일반 한국어 발음 커버리지를 메우는 용도이고,
# 도메인 성능은 오직 이 파일에서 나온다. 여기를 늘리는 게 제일 효과가 크다.
#
# 형식:
#   '## 그룹명' 으로 그룹을 나눈다 (wake / command / negative / general)
#   '#' 로 시작하는 줄과 빈 줄은 무시
#   한 줄 = 한 문장. 중복 줄을 넣지 마라 (반복 녹음은 record_dataset --passes 로 한다)
#   표기 원칙: 숫자·영문은 말하는 대로 한글로 쓴다 (3시 -> 세 시, USB -> 유에스비)
